# Cold Mill Risk Management - Public Releases

Este repositório armazena os arquivos de distribuição pública e atualizações do aplicativo **Cold Mill Risk Management**.

## Como funciona a atualização no App:
1. O aplicativo consulta o arquivo `version_info.json`.
2. Se `versionCode` for maior que o instalado, o usuário recebe um aviso para baixar o novo `ColdMillRiskManagement.apk`.

## Arquivos:
- `ColdMillRiskManagement.apk`: Aplicativo compilado para Android.
- `version_info.json`: Controle de versões e notas de lançamento.
